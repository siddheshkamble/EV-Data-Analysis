# Electric Vehicle Population Data Analysis

## Project Overview
This project analyzes Electric Vehicle (EV) population data to identify adoption trends, regional distributions, vehicle characteristics, and predictive insights using data analytics and machine learning techniques.

The analysis includes:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Linear Regression Modeling

---

# Dataset Information

The dataset contains information about registered electric vehicles, including:
- Vehicle Make and Model
- Electric Vehicle Type
- Electric Range
- Model Year
- CAFV Eligibility
- County and City
- Vehicle Location

Dataset used:
`Electric_Vehicle_Population_Data.csv`

---

# Objectives

The main objectives of this project are:
- Clean and preprocess EV data
- Analyze EV adoption trends
- Compare urban vs rural EV adoption
- Visualize EV distributions and patterns
- Build a Linear Regression model to predict Electric Range
